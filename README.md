# Kernel Patch Studio

A modern Vue 3 + Vite frontend prototype for kernel / boot.img patching and KPM module management.

## Features
- Upload kernel / boot.img files
- Upload multiple .kpm modules
- View module metadata: name, author, version, license, description
- Edit module event trigger and running parameters
- Simulated terminal console for patch logs
- Dark mode support and responsive mobile/desktop layout
- About and Version pages

## Run locally

```bash
npm install
npm run dev
```

Open the site at `http://localhost:5173` or the port displayed in the terminal.
